# Бот для заявок на онлайн-визитку

Бот: [@riakhin_card_bot](https://t.me/riakhin_card_bot)  
Репозиторий: `RiakhinA/card-bot`  
Сервис: Railway, service `card-bot`

## Что делает бот

1. Показывает примеры визиток и объясняет, что страницу можно поставить в Instagram или отправлять клиентам обычной ссылкой.
2. Собирает желаемое имя ссылки, имя и сферу, описание, фото/логотип или вариант без изображения, соцсети, контакты и проекты/ссылки.
3. Отправляет Антону структурированную заявку и фото отдельно.
4. Сообщает клиенту условия работы для текущего Pilot:

   - одна языковая версия: 1200 грн / $29;
   - две языковые версии: 1700 грн / $39;
   - способ оплаты выбирается в конце, а реквизиты отправляются после проверки заявки.

QR-кода в конструкторе нет.

## Как всё связано

**GitHub** хранит код и изображения бота.  
**Railway** запускает этот код круглосуточно. Он получает токен бота и настройки из переменных окружения.  
Когда Railway применяет новую версию из GitHub, бот перезапускается с обновлённым текстом.

Важные файлы:

- `bot.py` — логика, тексты и вопросы бота;
- `assets/` — четыре изображения-примера;
- `requirements.txt` — зависимости Python;
- `Procfile` — команда запуска;
- `runtime.txt` — версия Python.

## Как применяются изменения

### Тексты и логика

Тексты, вопросы, кнопки и изображения меняются в GitHub. После нажатия **Commit changes** Railway автоматически подхватывает новую версию из ветки `main` и запускает новый deployment.

Проверка: Railway → **Deployments**. У последней версии должен быть статус **Deployment successful**, а в карточке сервиса — **Online**. Обычно это занимает около минуты. В текущей настройке отдельную кнопку Deploy нажимать не нужно.

### Цена и оплата

Текущая Pilot-цена и правило полной оплаты определяются в runtime-коде `bot.py`. Переменные Railway `PRICE` и `PREPAY` не являются источником этих условий.

Для изменения коммерческих условий нужен отдельный согласованный change: обновить код, связанные тесты и затем пройти обычный Test Bot release path. Не менять условия напрямую через Railway variables.

В текущем Pilot бот не проверяет оплату автоматически: после проверки заявки Антон отправляет реквизиты для выбранного клиентом способа.

## Как поменять текст бота в GitHub

1. Открой репозиторий `RiakhinA/card-bot`.
2. Открой файл `bot.py`.
3. Нажми значок карандаша.
4. Найди нужную русскую фразу и измени её.
5. Нажми **Commit changes**.
6. В Railway проверь, что начался новый deployment. Если появился **Deploy Changes**, нажми его.

Токен бота в GitHub не хранится и не должен храниться. Он находится только в Railway в переменной `BOT_TOKEN`.

## Как проходят оплаты сейчас

После заявки клиент видит условия. Антон смотрит материалы и сам отправляет реквизиты в личном сообщении. Это безопаснее: номера карты, данные Payoneer и криптокошельки не лежат ни в коде, ни в GitHub.

Следующее улучшение, если понадобится: кнопка «Запросить реквизиты для оплаты» с выбором ПриватБанк, Payoneer или криптовалюта. Бот сообщит Антону выбранный способ, а реквизиты он отправит вручную.
